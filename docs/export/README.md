# Claude knowledge pack

Files here are generated by `npm run knowledge:export` from repo sources (glossary, domain types,
backend docs, and the schema table list). They give Claude — or a partner — Fabric Flo's product
language and backend model without touching the app or Supabase.

| File | Use |
|------|-----|
| `Fabric_Flo_Knowledge_Pack.md` | Upload to a Claude.ai Project, or paste into a chat. |
| `Fabric_Flo_Knowledge_Pack.pdf` | Share with investors or partners. |

## Use with Claude.ai Projects

1. Create (or open) a Project at [claude.ai](https://claude.ai).
2. Add to the Project knowledge: upload `Fabric_Flo_Knowledge_Pack.md` (or the `.pdf`).
3. Ask questions like "What is an Invite Code in Fabric Flo?" — answers should match the glossary.

## In Cursor

You do not need this pack in Cursor — the agent reads `.cursor/rules/` and `AGENTS.md` automatically
in this repo.

## Refresh

These files are generated; edit the source docs, not these. After changing terminology or schema:

```bash
npm run knowledge:export
```

Start edits in [`docs/FABRIC_FLO_GLOSSARY.md`](../FABRIC_FLO_GLOSSARY.md) (the source of truth).

## Safety

The pack contains no secrets, credentials, or user data — only docs and type definitions. The
exporter never connects to Supabase.
